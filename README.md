# 📦 Сканер кодов Честного знака

Локальное Python-приложение для автоматического поиска и извлечения кодов маркировки **«Честный знак»** из PDF-файлов.

Программа позволяет одновременно загружать несколько PDF-документов, автоматически просматривать все страницы, распознавать Data Matrix / QR-коды, сохранять полный код маркировки и экспортировать результаты в Excel или CSV.

Приложение предназначено для обработки документов с большим количеством кодов маркировки и позволяет быстро проверить, какие коды содержатся в конкретных PDF-файлах.

---

## ✨ Возможности

### 📄 Работа с PDF

* Загрузка одного или нескольких PDF-файлов.
* Обработка всех страниц выбранных документов.
* Одновременное сканирование нескольких PDF.
* Нумерация добавленных PDF-файлов.
* Отображение полного названия PDF.
* Горизонтальная прокрутка для длинных названий файлов.
* Возможность изменять размер области со списком PDF.
* Отображение количества найденных кодов для каждого документа.

### 🔎 Распознавание кодов

Поддерживается распознавание:

* Data Matrix;
* QR-кодов;
* кодов маркировки GS1.

Для повышения качества распознавания используются несколько методов обработки изображения:

* PyMuPDF;
* OpenCV;
* NumPy;
* zxing-cpp.

Программа последовательно обрабатывает страницы PDF и пытается найти коды даже в случаях, когда стандартного распознавания недостаточно.

---

## 🧾 Сохранение полного кода

Важная особенность программы — **полный код маркировки сохраняется без изменения криптографической части**.

Например:

```text
0104629318585038215ljR
0104629318585038215Mql
0104629318585038215/QF
0104629318585038215!Ks
```

Серийная и криптографическая части кода не обрезаются.

Также сохраняется специальный разделитель GS/FNC1:

```text
\x1D
```

Это позволяет использовать полученные данные для дальнейшей проверки и обработки кодов «Честного знака».

Поддерживается структура GS1 с идентификаторами применения (AI), в том числе:

```text
01 — GTIN
21 — серийный номер
91 — дополнительный атрибут
92 — дополнительный атрибут
```

Также учитываются варианты представления кодов с префиксами:

```text
(01)...
]d2...
```

## 📊 Работа с найденными кодами

После завершения сканирования программа отображает результаты в интерфейсе.

Для каждого найденного кода можно увидеть:

* полный код;
* PDF-файл, в котором он найден;
* номер страницы;
* количество найденных кодов.

Полный код отображается непосредственно в списке результатов.

Для дополнительной информации предусмотрена кнопка **«Подробности»**, где отображаются основные составляющие кода:

* GTIN;
* серийный номер;
* криптографическая часть.

---

## 📁 Группировка по PDF

Результаты связываются с исходным PDF-файлом.

Это позволяет быстро определить:

```text
PDF №1
 ├─ код 1
 ├─ код 2
 └─ код 3

PDF №2
 ├─ код 4
 └─ код 5
```

Таким образом, при обработке большого количества документов сохраняется информация о том, из какого именно файла был получен каждый код.

---

## ♻️ Удаление дубликатов

Программа выполняет удаление дубликатов по **полному коду**.

Например:

```text
0104629318585038215ljR
0104629318585038215ljR
0104629318585038215Mql
```

результатом будет:

```text
0104629318585038215ljR
0104629318585038215Mql
```

При этом разные серийные или криптографические части одного GTIN считаются разными кодами.

## 📥 Установка

Установите Python 3.10+.

Затем установите необходимые зависимости:

```bash
pip install pymupdf opencv-python numpy zxing-cpp openpyxl pywin32
или
pip install -r requirements.txt
```

После установки запустите приложение:

```bash
python scanner_chestny_znak_v2_6.py
```

Название запускаемого `.py`-файла может отличаться в зависимости от текущей версии проекта.

## 🚀 Использование

### 1. Добавьте PDF

Нажмите:

**«Выбрать PDF»**

и выберите один или несколько документов.

В списке каждый файл получает собственный номер.

### 2. Запустите сканирование

Программа последовательно обработает выбранные PDF и все их страницы.

### 3. Просмотрите результаты

После обнаружения код отображается в списке вместе с информацией о его источнике.

### 4. При необходимости откройте подробности

Выберите код и нажмите:

**«Подробности»**

чтобы посмотреть его составляющие.

### 5. Экспортируйте результаты

Используйте:

* **Excel** — для работы с таблицей;
* **CSV** — для универсального обмена данными.

## Как пользоваться готовым приложением

Приложение работает локально на компьютере пользователя.

PDF-файлы и найденные коды **не отправляются на сторонние серверы**.

Обработка документов выполняется непосредственно на компьютере.

Сканер особенно удобен при обработке:

* PDF с кодами Data Matrix;
* документов «Честного знака»;

## ⚠️ Важное замечание

Программа извлекает и сохраняет данные, закодированные в Data Matrix / QR.

Она **не заменяет официальные сервисы «Честного знака»** и не выполняет юридическую проверку действительности маркировки.

Полученные коды можно использовать для последующей проверки и обработки.
