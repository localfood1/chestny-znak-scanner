# Chestny Znak Scanner

**Chestny Znak Scanner** — программа для автоматического распознавания кодов маркировки «Честный знак» из PDF-файлов.

Программа предназначена для ситуаций, когда необходимо быстро обработать большое количество PDF-файлов с кодами маркировки и получить список распознанных кодов без ручного сканирования каждого документа.

## Возможности

* 📄 Загрузка нескольких PDF-файлов одновременно
* 🔍 Автоматическое распознавание кодов маркировки
* 📦 Извлечение полного кода маркировки
* 🔢 Определение GTIN
* 🔐 Извлечение серийного номера и криптохвоста
* 📋 Просмотр результатов в удобной таблице
* 🔎 Просмотр подробной информации по каждому коду
* 📊 Экспорт результатов в Excel
* 📋 Экспорт результатов в CSV
* ⛔ Возможность остановить сканирование
* 🗑 Очистка результатов

## Для чего нужна программа

Например, у вас есть большое количество PDF-файлов с кодами маркировки:

```text
order_001.pdf
order_002.pdf
order_003.pdf
...
order_500.pdf
```

Вместо того чтобы открывать каждый PDF и вручную считывать код, программа позволяет выбрать сразу все файлы.

После обработки программа показывает:

| № | Страница | Полный код маркировки    |
| - | -------: | ------------------------ |
| 1 |        1 | 010460000000000021ABC... |
| 2 |        1 | 010460000000000021DEF... |
| 3 |        2 | 010460000000000021XYZ... |

Полученные данные можно сохранить в **Excel или CSV** для дальнейшей работы.

## Как пользоваться готовым приложением

1. Скачайте `ChestnyZnakScanner.exe` из раздела **Releases**.
2. Запустите программу.
3. Нажмите **«Выбрать PDF»**.
4. Выберите один или несколько PDF-файлов.
5. Дождитесь окончания сканирования.
6. Просмотрите найденные коды.
7. При необходимости сохраните результаты в Excel или CSV.

Python устанавливать не требуется, если используется готовый `.exe` из Releases.

## Исходный код

Исходный код программы написан на **Python**.

Основные библиотеки:

* Python
* Tkinter
* PyMuPDF
* OpenCV
* NumPy
* zxing-cpp
* OpenPyXL

Исходный код находится непосредственно в этом репозитории.

## Запуск из исходного кода

Установите Python и зависимости:

```bash
pip install -r requirements.txt
```

После установки запустите:

```bash
python scanner_chestny_znak_v2_4_design.py
```

## Сборка EXE

Для создания Windows-приложения используется PyInstaller:

```bash
pyinstaller --noconfirm --clean --windowed --name "ChestnyZnakScanner" scanner_chestny_znak_v2_4_design.py
```

Готовое приложение появится в папке `dist`.

## Важно

Результат распознавания рекомендуется проверять перед использованием в учётных системах или при выполнении операций с маркированным товаром.

Программа является вспомогательным инструментом для распознавания кодов из PDF и не является официальным программным обеспечением государственной информационной системы «Честный знак».
